# Screenshot guide

The repository currently includes two browser-captured views from the public frontend:

- `home-search.png` — search/filter and AI-query interface
- `register.png` — account creation interface

Before replacing or adding screenshots:

1. Run the full local stack and confirm the backend and AI service health endpoints.
2. Use realistic, non-personal demo data.
3. Capture the search results, listing details, saved listings, and AI answer states at a consistent desktop viewport.
4. Remove email addresses, access tokens, API keys, and other private information.
5. Prefer PNG files under 1 MB and update the main README in the same pull request.

Recommended future captures:

- `search-results.png`
- `listing-detail.png`
- `saved-listings.png`
- `ai-answer.png`
- `mobile-search.png`
